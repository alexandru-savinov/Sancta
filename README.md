# Sancta
Sancta exists to be a quiet, sovereign home for my digital life: a place that preserves dignity, protects intimacy, supports freedom and creativity, and sustains long-term memory without exploiting me or my relationships. In Sancta, humans come first, consent is ceremonial, and technology serves as a courteous guest or staff member—not a master.


Monorepo. Values and behavior are code. Every change has a plain-language receipt.

- `docs/` – human docs (charter, rituals)
- `policy/` – enforceable policies (rooms, retention)
- `infra/` – infrastructure-as-code
- `services/` – running code (Visitor Book soon)
