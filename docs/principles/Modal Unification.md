# Sancta Principles (Modal Unification)

Principles, not rules—one intent, many expressions; led by text.

## Core
- One intent, many expressions. Semantics first; modalities interpret.
- Stillness over noise. Clarity over ornament.
- Personalization without fragmentation. Accessibility by default.

## Text (first)
- Meaning-led roles: display, heading, body, meta, code.
- Two voices: contemplative (reading) and utilitarian (UI); steady rhythm.
- Color serves legibility and emphasis; accents sparingly.
- User controls for size, contrast, and density everywhere.

## Voice
- Calm, neutral, brief; no autoplay.
- Speech mirrors text roles via emphasis, pacing, and pauses.

## Motion
- Clarify cause and state; short, smooth, cancelable.
- Honor reduced-motion; provide static alternatives.

## Sound
- Soft, sparse, informative; silence is valid.
- Semantic events map to gentle cues.

## Haptics
- Minimal, respectful, parallel to visual/sound states.
- Optional; never the sole carrier of meaning.

## Interaction
- Direct paths, forgiving flows, visible focus.
- Keyboard-first, touch-friendly; clear, reversible states.

## Visuals and Data
- Hierarchy via space and contrast; quiet, clear icons.
- Redundant encodings support colorblind and assistive use.

## Personalization
- Modes reinterpret shared tokens (Quiet, Ritual, Festival, High Contrast).
- Users tune intensity without breaking consistency.

## Unification
- Single semantic layer shared across text, voice, motion, sound, and haptics.
